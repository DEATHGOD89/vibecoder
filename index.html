Quick Start & Workspace Guide

Welcome to PromptFlow AI! This platform is designed to bridge the gap between sloppy conversational ideas and expert prompt layouts. Below is a breakdown of all core systems:

1. Quick Enhance

Paste any messy thought (e.g. "make a script to download files") and press Enhance Prompt. Our compiler automatically rewrites it with professional roles, deliverables checklists, and rule constraints.

2. Prompt Architect

Use our guided form-fields to compile structured templates step-by-step. Enter the AI's role, core goal, deliverables checklists, and strict rules to output highly reliable templates.

3. Vibe Shields

Enable key guardrails to lock down AI behaviors:
• Anti-Truncation: Stops AI from writing // ... rest of code.
• Plan First: Forces AI to reason step-by-step before code.
• Styling Lock: Locks unrequested framework changes.

4. Sloppy-to-Perfect Diff

Toggle Diff View in the Workspace header to see an elegant comparison: conversational fluff highlighted in red vs. injected structural headers in green.

5. Performance Auditor & Multi-Language

• AI Auditor: Inspect real-time cost and latency estimates comparing Gemini, GPT-4o, Claude 3.5, and DeepSeek-R1 models dynamically.
• Target Language: Select English, Spanish, French, Japanese, German, or Hindi to auto-translate compiled prompt structures and headers instantly.

6. Serverless Backup & Cloud Share

• Instant Share Link: Click "Generate Share Link" in Settings to copy a Base64 URL that replicates your exact prompt state for anyone instantly.
• JSON Exporter: Back up all history drawer items and model preferences to a local JSON file and restore it in seconds.
